# SynthID 검사 연결·표시와 공개 연구 검토

확인일: 2026-10-21. 이 문서는 1.3.0의 인수인계 기록입니다.

## 화면에서 탐지가 보이지 않았던 이유

`--scan`의 메타데이터·공개 코덱·주파수 검사는 SynthID-Image 해독기가 아닙니다. 앞서 브라우저에서 확인한 공식 양성 결과는 로컬 비교 JSON에만 있었고 앱에 연결되지 않았습니다. API 결과 역시 팝업에 표시한 후 저장할 수 있었지만 본 화면의 반원과 카드에는 전달되지 않았습니다. 반원은 처리 단계만 표시하여 메타데이터나 공개 워터마크가 검출되어도 `확인` 상태로 남았습니다.

1.3.0에서는 실제 검사 기록을 SHA-256으로 파일에 연결합니다. 코드나 배포 앱에 특정 샘플의 해시·파일명·판정을 넣지 않습니다. 외부 기록을 읽는 것은 새 검사를 실행하는 행위가 아닙니다.

| 상태 | 반원 | 의미 |
| --- | --- | --- |
| 양성 근거 있음 | 빨간색 · 탐지됨 | 제목에 SynthID, C2PA 출처, 메타데이터 또는 워터마크를 명시 |
| SynthID 기록 없음 | 주황색 · 미검사 | 로컬 검사가 끝나도 공식 픽셀 판정은 없음 |
| 연결한 제공사에서 음성 | 회색 · 미검출 | 해당 검사의 지원 신호가 발견되지 않음. 인간 제작의 증명이 아님 |
| 검사 오류·손상된 기록 | 주황색 · 검토 | 오류를 음성으로 바꾸지 않음 |

처리·저장 성공은 양성 판정을 덮어쓰지 않습니다. 원본/처리 후 탭이 각 파일의 기록을 사용합니다. 원본 양성 결과는 바이트가 달라진 처리본으로 승계되지 않습니다. C2PA의 SynthID 삽입 선언과 통계적 주파수 이상은 픽셀 양성 근거로 취급하지 않습니다.

## 기록 사용과 보안

`SynthID 공식 검사 → 현재 이미지의 검사 기록 가져오기`에서 JSON을 선택합니다. 앱에서 받은 OpenAI API 결과는 자동으로 연결되며 JSON으로 저장할 수도 있습니다. 웹 결과는 사람이 확인하여 옮긴 `official_web_observation`으로 구분합니다. 가져온 API 기록도 화면에서 가져온 기록임을 알립니다. **JSON은 검증기관의 전자서명 증명이 아니며 사용자가 수정할 수 있는 로컬 기록입니다.**

기록은 이미지·전체 경로 없이 사용자 데이터 폴더 `AI Unmarker Pro/verification-records`에 저장됩니다. 테스트에서는 `UNMARK_VERIFICATION_STORE`의 절대 경로로 격리합니다. 제공사는 Google/OpenAI, 신호는 SynthID/C2PA로 제한합니다. 128 KiB·최대 64개 기록 제한, 파일 해시 일치 검사, 날짜 검증, 원자적 저장을 적용합니다. URL이나 JSON에 포함된 경로는 실행하거나 조회하지 않습니다. 브라우저 로그인 정보 수집과 비공식 서버 호출을 추가하지 않았습니다.

기록 한 개 또는 `{"records": [...]}` 묶음을 사용할 수 있습니다. 다음은 형식 예시이며 실제 검사 결과가 아닙니다.

```json
{
  "schema": "unmarker.verification.v1",
  "sha256": "이미지의 소문자 64자리 SHA-256",
  "provider": "openai",
  "method": "official_web_observation",
  "checked_at": "2026-10-21T09:00:00+00:00",
  "signals": {
    "synthid": {"status": "detected"},
    "c2pa": {"status": "not_detected"}
  }
}
```

같은 파일·제공사는 검사 날짜가 최신인 기록을 사용합니다. 동일 날짜의 재가져오기는 마지막 저장이 반영됩니다. 날짜를 임의로 미래로 바꾸지 마십시오. 서비스 오류는 `error`, 실행하지 않은 검사는 `not_tested`입니다. 일반 AI 이미지 분류 점수는 이 형식으로 가져올 수 없습니다.

## 최신 공식 자료와 공개 구현의 채택 판단

1. [Google SynthID-Image 논문](https://arxiv.org/html/2510.09263v1): 학습된 삽입기·검출기를 설명합니다. 공개 평가 대상 SynthID-O는 정해진 변형 조건에서 낮은 오탐률에 맞춰 평가됩니다. 이를 모든 서비스·이미지의 정확도나 이 앱의 정확도로 옮겨 적을 수 없습니다. [공식 공개 저장소](https://github.com/google-deepmind/synthid-text)는 **텍스트용**입니다. 확인한 자료에서 배포된 이미지용 검출 가중치와 키를 받는 경로는 찾지 못했습니다.
2. [OpenAI Content Provenance API](https://developers.openai.com/api/docs/guides/content-provenance): 현재 연결 경로와 응답 형식이 공식 문서와 일치함을 재확인했습니다. C2PA·SynthID는 독립 결과이고, 미검출은 AI 생성 부정 판정이 아닙니다. 서비스 접근 권한과 키가 필요합니다. API 응답을 현재 이미지에 연결하는 누락을 수정했습니다. 이번 작업에서 실제 API 왕복은 수행하지 않았습니다.
3. [Rinne414/SynthID-detector](https://github.com/Rinne414/SynthID-detector/tree/b08abff06b67c37db9dfa7c6ed63760a446d560f): 템플릿 방식이 학습에 사용하지 않은 AI 이미지 33개 중 0개를 검출했다는 작성자의 정정이 있습니다. 새 CLIP 분류기는 일반 AI 분류이며 SynthID 해독기가 아닙니다. 두 방식 모두 SynthID 판정기로 채택하지 않았습니다.
4. [cpeoples/ai-watermark-detector](https://github.com/cpeoples/ai-watermark-detector): 이미지 SynthID는 주파수 기반 대리 지표라고 명시합니다. 앱의 기존 주파수 통계와 마찬가지로 공식 픽셀 판정을 대체하지 않으므로 추가하지 않았습니다.
5. [MarkNull 논문](https://arxiv.org/html/2608.10166v1), [저자 공개 코드](https://github.com/JieCaoSec/MarkNull/tree/4d4067d0ecd0cb2af2bcbf45132efae69b4b703f): 2026년 연구이며 Imagen-3 이미지 20개를 Gemini로 확인한 실험에서 제거 성공을 보고합니다. 이는 현재 OpenAI 이미지, 사용자의 두 샘플 또는 macOS에서의 검증이 아닙니다. 코드의 MarkNull-A는 약 481 MB 가중치 외에도 SD 1.5 VAE와 학습용 의존성을 사용하고, WRN 초기화 내부에 CUDA 고정 호출이 있습니다. 루트에 재배포 라이선스 파일은 없었습니다. 이 코드를 앱에 복사하거나 검증된 새 엔진으로 등록하지 않았습니다. 재현 우선 후보로 남기되 MPS 이식·가중치 권한·원본 해상도 유지·공식 전후 검사를 별도로 해결해야 합니다.
6. [UnMarker 저자 코드](https://github.com/andrekassis/ai-watermark): IEEE S&P 2025 연구 구현입니다. README는 고사양 NVIDIA GPU 32 GB 이상·CUDA 12를 요구하며, LICENSE는 연구·평가 목적의 비상업 사용으로 제한합니다. 현재 macOS 앱에 그대로 혼합하지 않았습니다. 저장소의 자체 SynthID 결과를 현재 두 샘플의 제거 성공으로 해석하지 않습니다.

## 이번 반영 범위

검사 기록 연결, 실제 근거에 따른 상태 우선순위, 공식 검사 카드, 원본/처리본 분리, 가져오기와 API 결과 반영을 구현했습니다. 시작 팝업은 제목-설명 간격 14px, 같은 설명 문장 간격 4px, 카드 내부 여백 16px, 창 외부 여백 20px를 사용하며 불필요한 최소 높이를 제거했습니다.

**새 제거 알고리즘의 효과를 검증한 것은 아닙니다.** 기존 양성 샘플은 Q4 처리 후에도 공식 OpenAI 검사에서 양성이었습니다. 원본이 음성인 다른 샘플은 제거 성공률의 분모로 사용할 수 없습니다. 기존 6개 화질 옵션 비교본도 일반 AI 분류 점수가 낮아지지 않았습니다. 기존 기록을 연결하는 과정에서는 이미지를 다시 업로드하지 않습니다.

## 다음 재현 작업의 기준

공식 양성 원본, 같은 제공사의 처리본 판정, 일반 이미지 음성 대조군을 준비합니다. 파일 해시·생성 경로·해상도·시드·모델 리비전·옵션·검사일을 고정해 기록합니다. 오류·미검사는 분모에서 제외하고 따로 세며, 원본 양성 중 처리 후 음성이 된 비율과 화질·글자 보존을 함께 보고합니다. 공식 서비스의 반복 요청을 이용한 파라미터 탐색은 하지 않습니다. 새 공개 모델을 채택하기 전에 배포 권한과 안전한 가중치 로딩, macOS 메모리 사용을 확인합니다.

수정할 파일은 `verification_records.py`(기록·해시·입출력), `provenance.py`(공식 API), `app_backend.py`(검사 결과 조립), `desktop_ui.py`(상태·카드·팝업)입니다. `main.py`는 `assemble_main.py`로 생성합니다.
