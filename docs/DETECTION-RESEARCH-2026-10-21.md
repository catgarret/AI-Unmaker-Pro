# SynthID 검사 정정과 공개 연구 검토

확인일: 2026-10-21. 현재 버전 1.3.1의 인수인계 문서입니다.

## 잘못 구현한 부분과 정정

1.3.0은 샘플의 과거 웹 검사 결과를 SHA-256으로 찾아 반원에 표시했습니다. 이것은 과거 판정 조회이며, 사용자가 요청한 새로운 이미지의 SynthID 검출 능력을 개선한 것이 아닙니다. 이 기능으로 검출 문제가 해결된 것처럼 진행한 판단은 잘못됐습니다.

1.3.1에서 자동 기록 조회와 JSON 가져오기, 해당 모듈을 제거했습니다. 이전 기록은 앱 검사에 읽히지 않습니다. 작업 중 생성한 샘플 판정 캐시는 앱 저장소에서 분리하여 로컬 검증 자료에 보관합니다. 과거 브라우저 실험 기록 자체는 재현 참고 자료로 남깁니다.

## 현재 기능을 정확히 구분하기

- 로컬 검사는 메타데이터와 등록된 공개 워터마크를 확인합니다. SynthID 이미지 검출기는 없습니다.
- 앱에서 사용자가 파일 전송에 동의하고 공식 OpenAI API 검사를 요청하면, 실제 응답만 현재 이미지에 반영합니다. 현재 파일의 해시는 요청한 바이트와 같은 파일인지 확인하는 데만 쓰며 판정을 찾는 키로 사용하지 않습니다.
- 새 파일과 다시 연 파일은 API 검사를 수행하지 않았다면 SynthID 미검사입니다. 오류와 누락은 미검출이 아닙니다.
- Google 공식 웹 검사는 별도로 사용해야 합니다. 자동 Google 판정 기능은 없습니다.
- API 키와 접근 권한이 없어서 이번 작업에서 실제 API 왕복을 수행하지 않았습니다. 회귀검사의 가짜 응답을 실제 서버 검증으로 설명하지 마십시오.
- Q4 처리한 기존 양성 샘플에도 SynthID가 남았습니다. 제거 문제는 해결되지 않았습니다.

## 최신 공식 자료와 공개 구현의 채택 판단

1. [Google SynthID-Image 논문](https://arxiv.org/html/2510.09263v1): 학습된 삽입기·검출기를 설명합니다. 공개 평가 대상 SynthID-O는 정해진 변형 조건에서 낮은 오탐률에 맞춰 평가됩니다. 이를 모든 서비스·이미지의 정확도나 이 앱의 정확도로 옮겨 적을 수 없습니다. [공식 공개 저장소](https://github.com/google-deepmind/synthid-text)는 **텍스트용**입니다. 확인한 자료에서 배포된 이미지용 검출 가중치와 키를 받는 경로는 찾지 못했습니다.
2. [OpenAI Content Provenance API](https://developers.openai.com/api/docs/guides/content-provenance): 현재 연결 경로와 응답 형식이 공식 문서와 일치함을 재확인했습니다. C2PA·SynthID는 독립 결과이고, 미검출은 AI 생성 부정 판정이 아닙니다. 서비스 접근 권한과 키가 필요합니다. API 응답을 현재 이미지에 연결하는 누락을 수정했습니다. 이번 작업에서 실제 API 왕복은 수행하지 않았습니다.
3. [Rinne414/SynthID-detector](https://github.com/Rinne414/SynthID-detector/tree/b08abff06b67c37db9dfa7c6ed63760a446d560f): 템플릿 방식이 학습에 사용하지 않은 AI 이미지 33개 중 0개를 검출했다는 작성자의 정정이 있습니다. 새 CLIP 분류기는 일반 AI 분류이며 SynthID 해독기가 아닙니다. 두 방식 모두 SynthID 판정기로 채택하지 않았습니다.
4. [cpeoples/ai-watermark-detector](https://github.com/cpeoples/ai-watermark-detector): 이미지 SynthID는 주파수 기반 대리 지표라고 명시합니다. 앱의 기존 주파수 통계와 마찬가지로 공식 픽셀 판정을 대체하지 않으므로 추가하지 않았습니다.
5. [MarkNull 논문](https://arxiv.org/html/2608.10166v1), [저자 공개 코드](https://github.com/JieCaoSec/MarkNull/tree/4d4067d0ecd0cb2af2bcbf45132efae69b4b703f): 2026년 연구이며 Imagen-3 이미지 20개를 Gemini로 확인한 실험에서 제거 성공을 보고합니다. 이는 현재 OpenAI 이미지, 사용자의 두 샘플 또는 macOS에서의 검증이 아닙니다. 코드의 MarkNull-A는 약 481 MB 가중치 외에도 SD 1.5 VAE와 학습용 의존성을 사용하고, WRN 초기화 내부에 CUDA 고정 호출이 있습니다. 루트에 재배포 라이선스 파일은 없었습니다. 이 코드를 앱에 복사하거나 검증된 새 엔진으로 등록하지 않았습니다. 재현 우선 후보로 남기되 MPS 이식·가중치 권한·원본 해상도 유지·공식 전후 검사를 별도로 해결해야 합니다.
6. [UnMarker 저자 코드](https://github.com/andrekassis/ai-watermark): IEEE S&P 2025 연구 구현입니다. README는 고사양 NVIDIA GPU 32 GB 이상·CUDA 12를 요구하며, LICENSE는 연구·평가 목적의 비상업 사용으로 제한합니다. 현재 macOS 앱에 그대로 혼합하지 않았습니다. 저장소의 자체 SynthID 결과를 현재 두 샘플의 제거 성공으로 해석하지 않습니다.

## 화면 개선과 유지보수

기존 왼쪽 이미지·오른쪽 결과 구조는 유지합니다. 결과 패널을 360px로 넓히고 카드 내부 여백은 14px, 카드 간격은 10px로 통일했습니다. 제목 11px, 판정 14px, 설명 12px로 구분하며 설명의 각 줄은 최소 줄 높이와 3px 간격을 사용합니다. 스크롤 영역과 검사 버튼을 분리하고 주 작업·처리 옵션은 같은 40px 높이를 유지합니다. 옵션창, 공식 검사창, 상세창도 같은 기준으로 정리했습니다.

수정할 파일은 ui_components.py(색상·여백·문단), desktop_ui.py(배치·상태), provenance.py(공식 API), app_backend.py(검사·처리)입니다. main.py는 assemble_main.py로 생성합니다. 새 네트워크 연결이나 의존성을 추가하지 않았습니다.

## 남은 일

처음 보는 이미지에 대한 실제 SynthID 검출은 확보되지 않았습니다. 공개 논문 결과를 앱의 검출률·제거율로 표시하지 마십시오. 새로운 제거 엔진을 채택하려면 macOS 호환성, 배포 권한, 실제 양성 이미지의 전후 공식 검사와 화질·문자 보존을 검증해야 합니다.
